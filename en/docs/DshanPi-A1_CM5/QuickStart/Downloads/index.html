资料下载

备用下载方式

如果下方链接无法打开或下载失败，可前往页末查看提取码和资料目录。百度网盘备用入口

硬件资料​

核心板​

资料查看与下载用途
核心板原理图原理图 V1（PDF）查阅核心板电路、信号名称及连接关系
核心板尺寸图尺寸图 V1（DXF）在 CAD 软件中核对核心板外形与机械尺寸
核心板封装库Allegro 封装（DRA）在 Cadence Allegro 中查看核心板封装，用于配套底板设计
核心板位号图位号图 V1.1（PDF）按原理图上的器件位号查找其在核心板上的位置

底板​

资料查看与下载用途
底板原理图（PDF，14 页）打开原理图查看接口针脚、信号连接、电源网络与器件电路
底板位号图（PDF，2 页）打开位号图根据原理图中的器件位号，在 PCB 上定位连接器、芯片、电阻和电容
开源底板 PCB 工程打开立创开源硬件项目查看 PCB 布局与布线，获取项目提供的设计资料

底板图纸对应的板名为 A1-CM5-Base-V1.2。查阅版本说明、核心板正反面 PCB 图和核心板资料入口，请打开 硬件资料。

软件资料​

系统固件​

按用途下载 DshanPI A1 CM5 的系统固件。两个 Armbian 版本均基于 Ubuntu 24.04，发布版本为 2026.10.10-1。

固件下载提示

系统固件文件较大。如下载较慢或中断，可前往页末的百度网盘获取 Armbian 桌面版、Armbian CLI 版或 Buildroot 固件。

系统版本适用场景获取链接
Armbian GNOME 桌面版连接显示器、键盘和鼠标，使用图形桌面下载桌面镜像（.img.xz） · 百度网盘
Armbian CLI 命令行版通过终端或 SSH 管理设备、部署服务下载 CLI 镜像（.img.xz） · 百度网盘
Buildroot 系统运行嵌入式应用，测试面向专用设备的固件百度网盘

下载 Armbian 后，使用同一发布版本的 SHA256SUMS 校验压缩包。下载 Buildroot 时，在网盘的 03_系统固件/02_Buildroot系统/ 目录选择 DshanPI_A1_CM5-buildroot.zip。

Windows 刷机资料​

资源下载入口用途
RK3576 SPL Loader v1.09.107rk3576_spl_loader_v1.09.107.binRKDevTool 的 Loader 文件，用于初始化下载所需的内存与存储访问
RKDevTool v3.32Windows 刷机工具在 Windows 上向设备写入镜像
DriverAssitant v5.1.1Windows USB 驱动让 Windows 识别 Rockusb 设备

Loader 文件大小为 774,649 字节，SHA-256 为 9aee33d44ecc4b30e76241a6aa6993e433edb42c4d92909aa55b81c21c142a9e。在 Windows 下载目录中可运行以下命令核对文件。

Get-FileHash -Algorithm SHA256 -LiteralPath '.\rk3576_spl_loader_v1.09.107.bin'

镜像校验见 选择系统与下载镜像，刷写流程见 向 eMMC 烧录系统。
