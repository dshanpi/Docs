DshanPi A1 CM5 使用指南

这套指南面向 DshanPi A1 CM5 核心板与官方底板，从选择系统镜像开始，介绍通过 Windows 电脑向 eMMC 安装系统，再完成首次登录、联网和日常使用。

第一次接触开发板，可以从 Armbian Ubuntu 桌面版入手。需要运行终端服务时选择 CLI 版；需要定制固件和修改驱动时，再阅读 Buildroot 与 SDK 章节。

教程版本

当前内容为 2026 年 11 月 12 日整理的初稿，以 CM5 Armbian Ubuntu 24.04 为使用主线。eMMC 刷机仍需补齐官方底板接线图、匹配 Loader 和实板验证。详细范围见 验证状态与后续内容。

想先认识接口，可以打开 交互认识主板，或直接进入 宽屏交互视图。

认清板型和操作位置​

A1 CM5 与原 A1 的镜像和接线图需要分别核对。 下载文件应包含 Dshanpi-a1-cm5，核心板与官方底板的版本都要记录。接口用途以对应底板标注和原理图为准。

教程中的操作分为三处：Windows 电脑负责下载与刷写；开发板终端负责登录、网络和日常配置；Linux 构建主机用于 SDK 编译。普通使用者无需先搭建编译环境。

当前镜像与更新状态​

本次核对的 CM5 2026.10.10-1 镜像 提供 CLI 和 GNOME 桌面版，仍标记为预发布。初始登录为 root / 1234，首次交互登录要求修改密码。

该版镜像与公开 APT 包集尚未完全对应，因此首次使用先完成开机与基本功能检查，系统更新另按 更新章节 核对条件。下载到镜像、刷写成功与实板功能通过，分别需要确认。
