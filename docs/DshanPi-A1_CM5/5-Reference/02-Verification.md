# 验证状态与后续内容

本套教程以官方 CM5 底板和 eMMC 为目标，当前为 2026 年 11 月 12 日整理的初稿。以下状态帮助读者区分已经核对的资料与仍需实板验证的操作。

## 已经核对的内容

- Wiki、论坛、相关源码仓库之间的职责和板型差异。
- CM5 `2026.10.10-1` Release 的状态、文件名、初始账号与发布方校验信息。
- 下载到的 `SHA256SUMS` 和 `release-provenance.json` 与 Release 中声明的摘要一致。
- 完整 Buildroot SDK 的配置、主要目录、CM5 设备树包含关系及固件封装标识。
- 镜像锁定版本中 dspi-config 的状态、软件源、Overlay 和更新命令入口。
- 当前公开 APT 包索引与镜像版本的对应情况。

源码检查、文件校验和实板运行是不同层次。这里没有将生成镜像或旧测试记录当成当前实板验证结果。

## 每章如何完成验证

按同一套硬件、同一镜像哈希从头操作，记录实际结果和失败分支。截图使用真实界面，接线图使用对应 CM5 底板照片；示意图只用于解释概念。

刷写成功后继续核对登录、存储、网络和冷启动。外设测试分别记录显示、键鼠、USB 存储、音频和无线的结果，避免用某个功能正常推断整板全部功能已通过。

## 后续专题

当前主线覆盖镜像选择、eMMC、首次登录、日常使用、更新恢复与排障。基础路径完成实测后，可继续增加：

| 专题 | 需要准备的实测内容 |
| --- | --- |
| TF 卡启动 | 冷启动、卡检测、与 eMMC 的启动选择 |
| 显示与触摸 | HDMI、MIPI、DP 各自的显示和输入验证 |
| 摄像头 | 实际传感器、媒体拓扑、AIQ、单路和多路图像 |
| 音频与蓝牙 | 播放、录音、配对与实际传输 |
| PCIe 与 NVMe | 共享接口影响、枚举和存储读写 |
| NPU 应用 | 匹配的运行库、模型和推理结果 |
| 系统定制 | 固定 SDK 输入、完整构建、镜像和实板验收 |

这些是内容规划，具体支持情况以相应专题的镜像与实测记录为准。
