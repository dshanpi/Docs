1. 底板断电时取出 TF 卡，拔下 USB 存储设备。用 **Type-C 数据线**连接电脑和底板的 [Type-C 下载口](/cm5/explorer?port=typec)，再将 **12V 电源**插入 [DC12V](/cm5/explorer?port=power)。
2. **按住上方的 MASKROM 键不放，短按一下下方的 RST（RESET）键。** 先松开 RST，再松开 MASKROM。
3. 确认 RKDevTool 底部显示 **发现一个 MASKROM 设备**，再开始写入。
