# 使用指南

本指南适用于 **DshanPI A1 CM5 核心板与官方底板**。需要图形桌面时，选择 Armbian GNOME 桌面版。只用命令行可选 Armbian CLI 版，需要定制嵌入式系统可选 Buildroot。

- **第一次使用开发板**，按顺序准备工具、连接硬件、下载镜像，再用 Windows 电脑将系统写入 eMMC。[从第一步开始](#第一次使用)
- **已经能够登录系统**，可以直接配置网络、安装软件，或开始编写应用、编译固件。[按任务查找教程](#已经能够开机)

## 第一次使用

想先认识接口，可以打开 [交互认识主板](./1-QuickStart/00-BoardExplorer.mdx)，或直接进入 [宽屏交互视图](/cm5/explorer)。

| 步骤 | 从这里开始 | 本章完成什么 |
| --- | --- | --- |
| 01 | [资料下载](./1-QuickStart/Downloads.md) | 获取底板图纸、USB 驱动和烧录工具 |
| 02 | [硬件连接](./1-QuickStart/HardwareConnections.md) | 对照 DshanPI A1 CM5 底板接线图，找到 Type-C 下载口、12V 电源口和 MASKROM 按键 |
| 03 | [选择系统与下载镜像](./1-QuickStart/01-Resources.md) | 下载并解压 DshanPI A1 CM5 专用镜像，选择 Armbian 时核对文件名中的 `Dshanpi-a1-cm5` |
| 04 | [向 eMMC 烧录系统](./1-QuickStart/02-FlashEMMC.md) | 进入下载模式，用 RKDevTool 写入所选系统 |
| 05 | [首次启动与登录](./1-QuickStart/03-FirstBoot.md) | 在开发板上设置 Armbian 登录账号，并在板端终端确认从 eMMC 启动 |

## 已经能够开机

### 系统配置

- 安装软件、使用 U 盘，或查看开发板的负载与温度。[常用系统操作](./SystemConfig/09-CommonOperations.md)
- 配置网络和远程登录、传输文件，或使用音视频和桌面应用。[系统配置与应用](/docs/DshanPi-A1_CM5/category/system-config)

### 应用开发

- 从 Hello World 开始，在 DshanPI A1 CM5 上用 GCC 和 Makefile 编译、运行 C 程序。[应用编程基础](/docs/DshanPi-A1_CM5/category/app-basic)
- 按示例采集摄像头图像、运行 NPU 模型，或开发 Qt 和 ROS 2 应用。[应用开发教程](/docs/DshanPi-A1_CM5/category/app-dev)

### 进阶系统开发

- 查找 DshanPI A1 CM5 的硬件图纸、系统镜像及对应源码。[资料与版本关系](./5-Reference/01-ResourcesAndVersions.md)
- 在 Linux 构建主机上选择 DshanPI A1 CM5 板级配置，编译生成可烧录的 `update.img`。[Buildroot SDK 与固件编译](./4-Development/01-BuildrootSDK.md)

### 更新排障

- 更新 Armbian 前，先确认软件源中有与当前 DshanPI A1 CM5 镜像匹配的板级软件包。[系统更新与恢复](./3-Maintenance/01-UpdateRecovery.md)
- 按刷机、启动、网络或外设的故障现象逐项检查，收集诊断信息。[常见问题排查](./3-Maintenance/02-Troubleshooting.md)

- 核对哪些操作已有实板验证，以及验证所用的板型和镜像。[教程验证状态](./5-Reference/02-Verification.md)
