# DshanPi-R1+ 介绍

**DshanPi-R1+** (RK3568) 是一款专为中高端性能需求设计的单板计算机 (SBC)。它集成了 **PCIe**、**USB 3.0**、**双千兆网口** 以及 **HDMI** 等丰富的高速接口，为您带来极致的连接与扩展体验。
