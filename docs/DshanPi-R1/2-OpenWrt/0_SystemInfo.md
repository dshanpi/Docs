# 系统简介

:::info 什么是 ImmortalWrt？
**ImmortalWrt** 是一款专门针对中国用户优化、基于 OpenWrt 的开源路由器固件。它致力于解决国内用户在使用原版 OpenWrt 时遇到的各种痛点，目标是提供一个 **开箱即用** 的网络定制化平台。
:::

## 核心特点

可以通过下表快速了解它的核心特色：

| 特性维度 | 具体描述与优势 |
| :--- | :--- |
| **项目定位** | OpenWrt 的第三方分支，专注于本土化优化与硬件支持。 |
| **核心优势** | **开箱即用**：针对国内网络环境预置优化（如全锥形 NAT）。<br/>**访问流畅**：提供国内软件源镜像，安装和更新速度大幅提升。<br/>**硬件友好**：支持小米、华为等大量国内主流路由器型号。 |
| **功能特色** | **界面友好**：提供完善的 LuCI 网页管理界面。<br/>**软件丰富**：拥有超过 800 个软件包，生态活跃。<br/>**高度可定制**：支持从源码编译，打造专属固件。 |
| **适用场景** | 家庭网络优化、软路由/旁路由搭建、网络开发与学习、老旧路由器功能焕新。 |

## 技术架构与核心亮点

ImmortalWrt 在继承 OpenWrt 强大基因的基础上，进行了多方面的针对性增强：

*   **本地化软件源**
    这是最直接的体验改善。项目提供并默认使用国内镜像源，彻底解决了插件安装和系统更新时可能遇到的下载缓慢或失败问题。

*   **增强的硬件兼容性**
    项目持续维护一个庞大的设备支持列表，特别增加了对小米、华为、华硕等品牌众多型号的支持，让更多设备能享受开源固件的强大功能。

*   **预置优化与丰富生态**
    固件默认集成了一些对国内网络环境有益的设置。同时，其软件仓库 (`package/feeds/`) 生态活跃，拥有超过 800 个软件包，方便用户按需安装。

## 主要应用场景

1.  **家庭网络深度优化**
    利用其丰富的插件实现广告过滤、异地组网、游戏加速、IPV6 支持等。还可以通过 **WDS (无线分布式系统)** 等功能，轻松组建家庭无缝漫游网络。

2.  **构建软路由或旁路由**
    ImmortalWrt 是 x86 软路由或旁路由系统的热门选择。可以在虚拟机、Docker 容器 (项目提供官方镜像) 或迷你主机 (例如：**DShanPi-R1+**) 上安装它，承担网络中的特定高级功能。

3.  **网络爱好者的学习与开发平台**
    它基于 Linux，是一个绝佳的学习网络协议和嵌入式开发的平台。并且可以学习如何从源码编译，定制属于自己的固件。

4.  **老旧路由器功能焕新**
    为一些官方已停止维护的路由器刷入 ImmortalWrt，不仅能获得最新的安全更新，还能解锁更多高级功能，延长设备寿命。

:::success 总结
总的来说，如果身处国内，希望获得比原厂固件更强大、比原版 OpenWrt 更易用的路由器系统，并愿意进行一些学习和动手，**ImmortalWrt** 是一个非常值得尝试的优秀选择。
:::
