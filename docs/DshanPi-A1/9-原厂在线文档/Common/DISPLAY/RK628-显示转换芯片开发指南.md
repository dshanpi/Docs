# RK628 显示转换芯片开发指南

本文档基于瑞芯微官方文档 `Rockchip_Developer_Guide_RK628_For_All_Porting_CN.pdf`（V2.6, 2024-08-06）整理，介绍 RK628 系列显示转换芯片的 For-All 驱动配置与调试方法。

:::info 适用范围
- **芯片型号**：RK628D / RK628F / RK628H
- **驱动框架**：Display 通路基于 MISC 框架（`drivers/misc/rk628/`），HDMI IN 通路基于 V4L2 框架（`drivers/media/i2c/rk628/`）
- **读者对象**：技术支持工程师、软件开发工程师
:::

---

## 一、概述

RK628 是 Rockchip 的显示转换芯片，支持多种视频输入输出格式转换。

**输入支持：** RGB / BT1120 / HDMI
**输出支持：** RGB / BT1120 / LVDS / GVI / DSI / CSI / HDMI

### 1.1 RK628D 主要规格

| Video Input | Typical Resolution | Typical Format |
| :--- | :--- | :--- |
| HDMI IN | 4K@30 | YUV420(4K@60) / YUV422 / YUV444 / RGB888 |
| BT1120 IN | 1080P@60 | YUV422 8bit |
| RGB IN | 1080P@60 | RGB888 |

| Video Output | Typical Resolution | Typical Format |
| :--- | :--- | :--- |
| GVI OUT | 4K@60 | RGB888 |
| MIPI CSI | 4K@30 | YUV422 8bit |
| MIPI DSI | 1080P@60 / 2.5K@60 | RGB888 |
| LVDS OUT | 720P@60 / 1080P@60 | RGB888 |
| BT1120 OUT | 1080P@60 | YUV422 8bit |
| RGB OUT | 1080P@60 | RGB888 |
| HDMI OUT | 1080P@60 | RGB888/YUV444 8bit |

### 1.2 RK628F 主要规格

相比 RK628D，RK628F 在 HDMI IN 支持更高规格：

| Video Input | Typical Resolution |
| :--- | :--- |
| HDMI IN | 4K@60 |
| BT1120 IN | 1080P@60 |
| RGB IN | 1080P@60 |

HDMI IN 支持格式：RGB888 / YUV422 8bit / YUV422 10bit / YUV420 8bit (&gt;4K@30Hz) / YUV420 10bit (&gt;4K@30Hz)

### 1.3 RK628H 主要规格

### 1.4 RK628F/H vs RK628D 改进

- HDMI IN 支持更高分辨率和更多格式
- 支持双 MIPI 模式（RK628F/H）
- 更多功能优化

## 二、驱动架构

### 2.1 Display 通路（MISC 驱动）

**代码路径：** `drivers/misc/rk628/`
- 支持 RGB / BT1120 / HDMI 输入
- 支持 RGB / BT1120 / LVDS / GVI / DSI / HDMI 输出
- 基于 DRM 框架

### 2.2 HDMI IN 通路（Media 驱动）

**代码路径：** `drivers/media/i2c/rk628/`
- 支持 HDMI 输入
- 支持 CSI / BT1120 输出
- 基于 V4L2 框架

两套代码相互独立，可单独编译运行。

### 5.7 显示常见问题处理

#### 5.7.1 没有生成 regmap 节点

- 检查 I2C 地址是否正确
- 检查供电是否正常

#### 5.7.2 I2C 通信异常

- 检查 I2C 引脚配置
- 测量 I2C 信号

#### 5.7.3 DSI 或 GVI 显示有内容但花屏

- 检查数据格式配置
- 检查 lane 顺序和极性

#### 5.7.4 提高 clock-frequency 后 DSI 无法显示

- 检查带宽是否足够
- 调整 PHY 参数

#### 5.7.5 显示有偏移问题

- 检查时序参数
- 调整 HBP/HFP/VBP/VFP

#### 5.7.6 如何操作 RK628 的 GPIO

通过 regmap 读写 GPIO 控制寄存器。

| :--- | :--- |

| 信号识别不到 | 检查 HDMI 源和线缆 |

| 显示只有一半画面 | 检查双 MIPI 配置、lane 映射 |
| 抓图失败 | 检查内存、分辨率配置 |
| APK 打开失败 | 检查应用权限、驱动绑定 |
| DTS 连接到 rkcif 预览失败 | 检查链路配置 |
| RK628 GPIO 操作 | 通过 regmap 操作寄存器 |
| 声卡注册失败 | 检查 I2S 配置、DTS |
