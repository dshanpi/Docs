## 概念介绍

### 概念解释

随着外围设备增加以及成本约束，很多外设希望使用 SOC 的 IO 输出某些特定时钟频率来替代外部晶振，从而减少外围电路成本。

### 主要配置

SOC 上 IO 输出 CLK 的前提是该 IO 的 IOMUX 有 CLK 输出功能。

**1. IOMUX 配置**

IO 的 IOMUX 必须配置成 CLK 输出功能。

**2. CLK 频率配置**

需要配置 CLK 频率。因为是替代外部晶振的：
- 如果输出 24M 且从 SOC 晶振 bypass → 信号质量最好
- 如果从 PLL 分频下来 → 信号质量稍差，是否满足外设需求看外设参考文档

**3. IO 驱动能力**

有的 IO 上波形不好看，可能需要调整 IO 的驱动能力。
